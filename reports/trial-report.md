- 環境: Python 3.14.0、pandas 2.3.3、openpyxl 3.1.5。

## 3. e-Gov 法令 API v2 で法令ID を決める(`out/04b_match_laws.txt`)

### 仕様の確認

公式の Swagger UI(https://laws.e-gov.go.jp/api/2/swagger-ui)が読み込む `lawapi-v2.yaml`(version 2.1.139)を `data/api/spec/` に保存し、そこで確かめた。使ったのは次の2つ。
- `GET /laws`(法令一覧): `asof`、`limit`、`offset` などを指定できる。
- `GET /law_data/{法令ID}`(法令本文): `asof` を指定できる。JSON 本文は試行版と明記されている。

仕様書の中に、呼び出し回数の上限は書かれていなかった。今回は依頼どおり1秒に1回以下に抑えた。

### 法令一覧

| 取得条件 | 件数 | 内訳 |
|---|---|---|
| `asof=2025-11-01` | 9,418 件 | 廃止等の状態: None 8,902 / Repeal 374 / LossOfEffectiveness 105 / Expire 37 |
| 時点指定なし(現時点) | 9,571 件 | — |

`mission=Partial`(一部改正法令)を指定すると、asof を付けても付けなくても 0 件だった。**一部改正法令は一覧に出てこない。**

### 照合の段

照合先は asof=2025-11-01 の一覧。上の段で決まった行は、下の段に回さない。

- **(a) 法令番号で一致**: R6 から引き継いだ法令番号が、一覧の `law_num` と完全に一致する場合。引き継ぐのは、R6 と R7 で法令名が同じ行に限った。ただし R7 の名前がちょうど72文字で、R6 の名前の先頭部分と一致する行(切れていると見られる行)も引き継ぎの対象にした。R7 の名前が一覧の題名とそのまま一致する場合は、切れていないとみなして対象から外した。
- **(b) 法令名が完全に一致**: R7 の法令名が一覧の `law_title` と完全に一致する場合。
- **(c1) 表記のゆれを直して一致**: 次の処理をしてから比べた。
  - NFKC 正規化、空白の除去
  - 数字の間のダッシュ類をそろえる
  - ヶ→ケ、「」の除去
  - 末尾の「抄」「附則」の除去
  - 一覧側で「昭和二十二年法律第五十四号（○○法）」の形をした題名は、括弧の中の名前でも引けるようにした
- **(c2) 補助の小段(依頼の (a)〜(c) の外)**: (c1) と同じ正規化をした上で、現時点の一覧の題名(改題後)と一致する場合。

いずれの段も、候補が複数あるときは「廃止等でないものが1件だけ」の場合に限って決めた。

- (c1) の 53 行は、すべて「私的独占の禁止及び公正取引の確保に関する法律」だった。e-Gov 側の題名が「昭和二十二年法律第五十四号（私的独占の禁止及び公正取引の確保に関する法律）」の形になっているためである。

- **点検**: (a) で決めた行のうち、R7 の法令名が一覧にある**別の**法令の題名と完全に一致するものが 8 行あった。R6 の法令番号と R7 の法令名が食い違っているが、どちらが正しいかは**分からない**。

## 4. 層別抽出 500 行の条文照合(`out/05_sample_check.txt`)

### 抽出の方法

- 層は「所管府省庁 × 手続類型」で、全部で 137 層。
- 行数を各層の大きさに比例して割り振り、端数は最大剰余法で配った。1行以上割り当てられた層は 81、0行の層は 56 ある。
- 層の中では無作為に抜いた(`numpy.random.default_rng(20251101)`)。母集団は R7 の 76,275 行。
- 抽出行の法令ID の段: (a) 483 / (b) 16 / 決まらない 1。

### 根拠条項号の分け方

- NFKC 正規化と空白除去のあと、`^(附則)?第N条(のN)*(第N項)?(第N号(のN)*)?$` に完全一致するものだけを分けた。N は算用数字か漢数字。
- これに合わないもの(列挙、準用、項だけ、イロハ、`第NのN条` など)はすべて「分けられない」とした。
- `附則第N条` は、原文の附則(`AmendLawNum` の無い附則)の中から探した。

### 照合の方法

- `GET /law_data/{法令ID}?asof=2025-11-01&response_format=json&json_format=full` で本文を取った。条は本則の `Article@Num`、項は `Paragraph@Num`、号は `Item@Num` で引いた。
- 項の指定が無く号だけが指定されている場合は、その条の項が1つだけなら、その項の号とみなした。
- 取得した本文は 353 法令。取得の失敗は 0。

### 結果(500 行)

| 結果 | 行数 | 割合 |
|---|---|---|
| 号まで一致 | **9** | 1.8% |
| 項まで | **358** | 71.6% |
| 条まで | **115** | 23.0% |
| 法令はあるが条が無い | **1** | 0.2% |
| 分けられない | **16** | 3.2% |
| (追加区分)法令IDが決まらない | 1 | 0.2% |

「法令IDが決まらない」は依頼の5区分に無いため、別に立てた。該当するのは手続ID 1024(〔旧〕公正取引委員会の審判に関する規則 第15条第7項)。

内訳。「号まで/項まで/条まで」は、指定された一番深い階層まで見つかったかどうかで分けている。

| 結果 | 補足 | 行数 |
|---|---|---|
| 号まで一致 | 項・号とも指定あり | 8 |
| 号まで一致 | 項の指定なし(項が1つの条) | 1 |
| 項まで | 号の指定なし | 357 |
| 項まで | 号が見つからない | 1 |
| 条まで | 項・号の指定なし | 112 |
| 条まで | 項が見つからない | 1 |
| 条まで | 項の指定なしで号(項が複数あり決められない) | 2 |

「項まで」「条まで」の大半は、原文がそもそもその深さまでしか書いていないためで、照合に失敗したわけではない。指定された階層が見つからなかったのは、次の3行だけだった。
- 項が見つからない: 1 行
- 号が見つからない: 1 行
- 条が無い: 1 行

分けられなかった 16 行の原文:
- `第50条の6第1項、第2項`
- `第7条第1,2項`
- `第151条で準用する第137条第3項`
- `第3項`
- `第20条第1項、第2項、第3項、第4項`
- `第2条第6号ハ`
- `第31条で準用する第8条第1項`
- `第40条において準用する第16条第1項`
- `第NのN条` 型 8 行: `第2の2条第1項`、`第2の3条第5項`、`第13の2条第1項` ×2、`第15の2条第12項`、`第50の9条第1項`、`第37の10条第1項`、`第55の4条第10項`

`第NのN条` 型を `第N条のN` と読み替えれば分けられる可能性はある。ただし、その読み替えが正しいかは確かめていない。

## 7. まとめ(数字から言えること/言えないこと)

言えること:
- **法令ID まで**: R7 の 99.09% の行で、e-Gov の法令ID を機械的に決められた。大半(95.60%)は、R6 の法令番号を手続ID で引き継いで決まった。R7 には法令番号列が無いので、**R6 が無いと (b) 以降の名前合わせに頼ることになる**。その場合に何%決まるかは、今回は測っていない。
- **条文まで**: 抽出 500 行では、根拠条項号を機械的に分けられたのが 96.6%(483 行)。そのうち 482 行は、指定どおりの条が 2025-11-01 時点の本文にあった。指定された階層が見つからなかったのは、項 1 行、号 1 行、条 1 行だけ。一方、原文が号まで書いている行は少なく(500 行中 号まで一致 9)、**根拠条項号の粒度はほとんどが項か条**。
- **障害になりそうなもの**:
  - R7 の法令名が72文字で切れている(383 行)
  - 2025-11-01 より後の改題が R7 の法令名に反映されている
  - 一部改正法令の附則を根拠とする行がある(API の一覧に無く、試した1件は本文も 404)
  - `第NのN条`・準用・列挙などの書き方
  - R6 法令番号と R7 法令名の食い違い(8 行)

言えないこと・分からないこと:
- 500 行の結果を母集団全体の割合として読むときの誤差幅は、計算していない。また、比例配分で 0 行になった 56 層は抽出に含まれていない。
- 条が見つかったことは、その条が本当にその手続の根拠であることを意味しない。内容が合っているかは確かめていない。
- 告示や一部改正法令が API の他の方法(キーワード検索API、法令履歴一覧取得API など)で取れるかは、試していない。
- 「食品等の流通の合理化…法律」の件は、2025-11-01 の一覧の題名がなぜ新しい題名になっているのか(改題の施行日の扱い)が分からない。
