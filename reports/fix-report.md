## 1. 「入れ替わった」

### 方法

- 「文言が変わった」2,737 行(異なる要素 1,811、法令 416)が対象。
- 同じ番号の旧い文言と新しい文言の近さを `difflib.SequenceMatcher(autojunk=False).ratio()` で測った。

## 2. 残りの「文言が変わった」を「番号の参照だけ」と「それ以外」に分ける

残りは 2,139 行(近さ 0.6 以上)。

### 決め方

1. 旧・新の文言を語に分ける。「並びに」「から」「まで」「及び」「又は」と、漢数字(〇一二三四五六七八九十百千)の連なりをそれぞれ 1 語とし、ほかは 1 字を 1 語とした。
2. その語の並びで差を取る(`difflib`、autojunk=False)。
3. 差の部分が、旧・新の両側とも次の語だけでできている行を「番号の参照だけ」とした。
   - 漢数字、第、条、項、号、の、「、」、並びに、から、まで、及び、又は

| 分類 | 行 | 異なる要素 |
|---|---:|---:|
| 番号の参照だけ | 437 | 223 |
| それ以外 | 1,702 | 1,108 |

| 深さ | 番号の参照だけ | それ以外 |
|---|---:|---:|
| 条 | 179 | 508 |
| 項 | 227 | 1,124 |
| 号 | 31 | 70 |

例(各要素の最初の違う箇所。[旧→新]):

- 番号の参照だけ
  - 風俗営業等の規制及び業務の適正化等に関する法律 第31条の23: …第四条第一項第六号[及び→から]第七号…
  - 金融機能の強化のための特別措置に関する法律 第14条第8項: …次項[→第一号及び第二号並びに第十二項]において同じ。…
  - 暴力団員による不当な行為の防止等に関する法律の規定に基づく意見聴取の実施に関する規則 第34条第4項: …とあるのは[→、]「第三十四条第三項…
- それ以外
  - 災害対策基本法 第64条第9項: …又は[内閣府→防災庁]令で定める…
  - 人事院規則九―三四(初任給調整手当)第6条第4項: …の適用により[→第一種]初任給調整手当の月額…
  - 私的独占の禁止及び公正取引の確保に関する法律 第70条の9第1項: …民事訴訟法第[百九→百]条の規定…
    - 最初の違う箇所は番号だけだが、同じ要素のほかの箇所に「第八十一条第三項において同じ。」の挿入がある。「において同じ。」が許される語ではないので、「それ以外」に入った(スクリプトで差を出して確かめた)。

### 注意: 漢数字の差は、番号の参照でなくても「番号の参照だけ」に入る

- 金額・日数・年の変更も、差が漢数字だけなら「番号の参照だけ」に入る。
- 分類は変えていない。そのかわり、疑いのある行を数えた。
  - 定義: 差が漢数字だけで、直前が旧・新とも「第」「の」でなく、直後が旧・新とも「第」「条」「項」「号」「の」でない箇所がある行。
- **数(金額・日数など)の変更の疑い: 21 行**(異なる要素 14)。437 行の内数。

| 法令・条項号 | 違う箇所 |
|---|---|
| 一般職の職員の給与に関する法律 第22条第1項 | …勤務一日につき、三万[四千七百→五千七百]円… |
| 労働者災害補償保険法施行規則 第46条の20 | …「[三十一→三十三]万五千円に給付基礎日額」… |
| 国民年金法施行規則 第31条 | …が[三百七十六→三百八十五]万千円を超える者… |
| 特定障害者に対する特別障害給付金の支給に関する法律施行規則 第1条 | …が[三百七十六→三百八十五]万千円を超える者… |
| 関税暫定措置法 第8条第1項 / 第4条 | …令和[八→十一]年三月三十一日までに… |
| 租税特別措置法 第90条の3の4第1項 | …令和[八→十一]年三月三十一日までに… |
| 法人税法施行規則 第54条 | …別表[二十二→二十四]に定めるところにより… |
| 森林経営管理法 第11条第6号 / 第25条第3号 | …起算して[六→二]月以内に… |

- 法人税法施行規則の「別表二十二→二十四」は別表の番号の参照だが、この定義では疑いに入る。
- 「万」は漢数字の集合に入れていない。そのため「三万」の「万」は 1 字の語として扱った。
- この定義でも拾えない数の変更がある可能性はある。確かめていない。

全行は `out/fix_rest.csv` にある(「番号の参照だけ」「数の変更の疑い」の列を含む)。

- 0.6(入れ替わった)、0.90 と 0.60(移った・消えた)は私が決めた値で、点検で確かめていない。`review-sample.csv` と `review-moves-090-095.csv` で点検する前提。
- 「番号の参照だけ」は差の文字の種類だけで決めている。参照先が変わったのが単なる番号の付け替えか、別の規定を指すようになったのかは分からない。数の変更が混じる点は 2 節に書いた。
- 「移った」は文言が近い要素が別の番号にある、というだけ。改正法の本文で繰上げ・繰下げを確かめてはいない。
- 例は、各要素の最初の違う箇所だけを示している。同じ要素のほかの箇所に、別の違いがあることがある。
